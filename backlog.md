**Global constraints:** All implementation occurs only on `overhaul`; no alteration to `main` or `baseline/v11`, no migrations or backwards-compatibility layers, no framework replacement merely for aesthetics, no CDN/network or fabricated official exam data, no pre-submit answer/editorial disclosure. Preserve Q62 user policy; current six-kind scoring, saved timing, FSRS, original/reviewed provenance, offline `file://`, native Navigation API/Safari hash fallback, current backup correctness, accessibility and 195px + 140% no-overflow. Retire obsolete internal code after complete replacement; do not retire meaningful safety tests. Five-step process for each P47 stage: **audit → analysis → implement → objective reconciliation → targeted QA + required CI**.

## After P48 / deferred backlog

- **Mathematical renderer (P47-X):** defer until concrete complex notation from authored exam banks demands it and user approves. If authorized later: explicit math authoring format, accessible textual fallback, hostile-input validation, pinned local renderer (if needed), measured bundle cost and all-context offline testing. Current CGL source uses Unicode radicals/exponents but no explicit TeX source.
- **Keyboard shortcut remapping (P47-K optional):** no new settings UI unless user requests it or demonstrable accessibility/conflict evidence justifies it; fixed, documented shortcuts remain supported and may be cleaned up under P47-4.
- **Exam package extensions (I18/I19/I21/I24):** individual question deadlines, unscored surveys, verified content banks, PWA/cloud/remote sync remain outside the P47 implementation unless separately approved, as registered in the canonical programme.
- **P48 manual/external:** physical macOS Safari and native mobile, real screen readers, OS kill/eviction and independent end-to-end release verification remain NOT TESTED without actual evidence.

**P47-0 success is not approval to start a P47-6 code rewrite without the baseline's explicit complete ownership/interface matrix and the existing user-approved architectural boundaries.**
