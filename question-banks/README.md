# Practice Desk question banks\n\nExam data lives here, not under `src/` or `examples/`. One folder per examination family; `pyqs/` for source-backed previous papers, `mocks/` for original practice papers, explicit `original/` and `revised/` editions, `archive/` for recovery material, and `catalog.json` as the machine-readable preinstall index. Disable/remove a catalog entry and rebuild to remove a preinstalled family; append a package entry to add a paper.\n
